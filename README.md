# comfort-defender
Transition to using the Defender Portal! *...But with more comfort*.

A series of tampermonkey scripts to make your Defender portal experience a bit easier and more efficient!

## Prerequisites

You need the [Tampermonkey](https://www.tampermonkey.net/) extension installed in your browser.

Then create a new script and copy and paste from the source here. Edit if you like!

# Scripts

- **Defender navigation pane (sic) helper** - a floating favourites bar which should (hopefully) be right next to the hamburger menu!
	- Add or remove or reorder your own!
	- *Win fabulous prizes**!

- **Security Center Auto Refresh on Idle (SCARi)** - refreshes the Incidents view if the page is idle. Configure your own interval!
